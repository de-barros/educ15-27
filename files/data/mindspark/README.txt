What these files are
These are the data sheets from the workbook used in EDUC 15 in Fall 2024,
saved as CSV. All 36 variables and all rows from that workbook are included.

- ms_blel_jpal_long.csv: 1,158 rows, one per student per round
- ms_blel_jpal_baseline.csv: the 619 baseline rows
- ms_blel_jpal_endline.csv: the 539 endline rows
- codebook.csv: what each variable means

What we changed
- Saved the workbook's sheets as CSV files.
- In the codebook, corrected the labels of quint_hindi1 and terc_hindi1, which
  said "math" instead of "Hindi".

The course workbook wasn't compared with the replication package, so use the
package itself if you need the authors' original files. The study's authors
aren't connected with this course and haven't endorsed it.
